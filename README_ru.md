### 🧠 Чем я занимаюсь

Я создаю системы и ML-инструменты **с первых принципов** — без обхода сложностей высокоуровневыми фреймворками, когда важно понять внутреннее устройство. Мои проекты реализованы без привычных «лёгких» библиотек: Hugging Face `Trainer`, FAISS, Gymnasium или autograd. Поэтому я понимаю и контролирую лежащие в их основе механизмы.

Я использую ИИ, чтобы учиться, создавать и понимать, как всё работает в процессе — как партнёра для размышлений, а не замену собственному пониманию. Я работаю с Claude Code и OpenCode; [Claude.ai](https://claude.ai) использую для идей и архитектурных решений, а ChatGPT — чтобы разбирать ещё непонятные мне закономерности в коде.

- 🌱 Изучаю локальный запуск LLM (Ollama, GGUF, квантизация), внутренние механизмы инференса (PagedAttention, KV-кэш) и аналитическую теорию чисел
- 💬 Спрашивайте меня об устройстве трансформеров, reverse-mode autodiff, векторном поиске (HNSW) и асинхронной архитектуре Python
- 🌍 Нахожусь в Астане, Казахстан
