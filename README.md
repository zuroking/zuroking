### 🧠 What I do

I build systems and ML tools **from first principles** — no shortcuts through high-level frameworks when the goal is to understand the internals. My projects are implemented without the usual “easy” library (no Hugging Face `Trainer`, FAISS, Gymnasium, or autograd), so I fully own and understand the underlying mechanics.

I use AI to learn, build, and understand how things work throughout the process — as a thought partner, not a replacement for understanding. I work with Claude Code and OpenCode; I use [Claude.ai](https://claude.ai) for ideas and architecture decisions, and ChatGPT to unpack patterns in code that are still unclear to me.

- 🌱 Exploring local LLM deployment (Ollama, GGUF, quantization), inference internals (PagedAttention, KV cache), and analytic number theory
- 💬 Ask me about transformer internals, reverse-mode autodiff, vector search (HNSW), and async Python architecture
